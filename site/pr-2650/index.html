ADK versionMediumThe page never says which ADK it targets. On ADK 1.39.1 the root span is invocation and the plugin writes the answer to a child span, Agnost's own ADK guide says transcripts are built from the root span, so on 1.x the root carries no answer. I tested with a local receiver, not Agnost's dashboard.

The fix is one sentence under the Installation block, in the review's suggestion format:

docs/integrations/agnost.md:42
+ This page is written for ADK 2.x and was tested on 2.15.1. On ADK 1.x,
+ see the [Agnost AI ADK guide](https://docs.agnost.ai/google-adk).

The second line only helps if the Agnost guide covers 1.x. My plugin fix handles both versions by saving the root span at the start of each turn.

What I would do in week one

Make it easy to approve

Add the version line, then post a short self review in the PR with the checklist result and "verified against v2.15.1". A maintainer working through 110 pages can approve a pre-checked one in minutes.

Don't wait for the merge

The same guide already lives on docs.agnost.ai/google-adk. Add the version note and a 1.x variant of the plugin there now, so 1.x users get answers on the root span today.

Check it every Monday

A small scheduled check on the PR and the queue data above can flag a maintainer comment or the first outside merge, so the PR gets a reply the same day.
